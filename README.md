# R116 indirme

Core of Life için R116_ADMISSION_TRANSFER1 düzeltmesi. Yalnız tam
R115_SHARED_SCOPE1 üzerine, Efsane ve Akademi birlikte.

Büyük oyuncu verisinin giriş/kurtarma sırasında IPC sınırına takılması
düzeltilir. Oyuncu DB ve şeması değiştirilmez.

Paket: r116-onarim.zip. SHA256 değeri SHA256SUMS dosyasında.
Kurulumdan önce bakım açık olmalıdır. ZIP içindeki KURULUM.md dosyasını okuyun.
Bu dal yalnız doğrulanmış paketin indirilmesi içindir; otomatik kurulum yapmaz.
