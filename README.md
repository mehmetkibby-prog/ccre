# Core of Life — R67 toplu güncelleme

[R67 paketini indir](https://github.com/mehmetkibby-prog/ccre/raw/refs/heads/r67-download/CORE511_R67_TOPLU.zip)

Başarıyla kurulmuş **R66 üzerine** uygulanır. Giriş hızı iyileştirmesi ve İlk Adımlar yönlendirme düzeltmesi tek pakettedir.

- İlk Adımlar balonunun geç yerleşen menüde Işınlanma düğmesini kapatması düzeltildi. Masaüstü ve mobilde denendi.
- Aynı kurulum ayarlarıyla 50 oyuncu testinde ilk giriş yanıtı p95: **1,642 → 1,368 saniye** (yaklaşık %17).
- Giriş, bağlantı, ışınlanma, başlangıç ödülü ve tekrar giriş: **50/50**. Savaş kontrolünde tamamlanmamış ödül ve çift anahtar: **0**.
- Ön kayıt/hesap hizmeti, kayıtlar ve açılış ayarları korunur. Kurulum oyun süreçlerini yeniden başlatır.
