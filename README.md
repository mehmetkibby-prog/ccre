# R119 — Şampiyonlar Diyarı animasyon düzeltmesi

Dört canavarın görünümü korunarak yürüyüş, saldırı ve duruş davranışları
Kuzey Ormanı’nın mevcut animasyon çizicisine bağlandı.

- İndir: [r119-animasyon.zip](r119-animasyon.zip)
- [SHA256](r119-SHA256SUMS.txt) · [Kurulum](R119-KURULUM.md)
- Kaynak sürüm: tam R118_ROYAL1; hedef: R119_MOTION1.
- Efsane ve Akademi birlikte; yalnız beş istemci dosyası.
- Masaüstü/mobil oyun, animasyon, kurulum/geri dönüş ve sekiz kanal açılışı yerelde doğrulandı.
- Bu paket canlıya otomatik kurulmamıştır.

Önce SHA256 ve `--check`, sonra panelden bakım geri sayımı ve `--apply`.
Eski R118 arşivi geçmiş teslimat olarak korunur; bu güncellemenin yerine tekrar kurulmaz.
