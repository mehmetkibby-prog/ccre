# Archived one-shot authoring scripts

These scripts record the first development pass of the R118 champions-map integration. They are **not regenerators** and must not be executed against the current source tree. They are not idempotent and do not contain the subsequent startup, PvP, respawn, or scattered-spawn corrections.

The final checked-in runtime sources, their reviewed diffs/proofs, and the executable R118 tests are the contract. The installer copies the final sources; it never runs these drafts. `../../evidence/champions-patch.json` is historical evidence of that first pass, not a final hash manifest.
